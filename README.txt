ALPINA SEO AUDIT – GITHUB PAGES
================================

1. ZIP-Datei entpacken.
2. Den Inhalt des Ordners in ein GitHub-Repository hochladen:
   - index.html
   - assets/audit-shop-availability.png
3. Im Repository öffnen:
   Settings > Pages
4. Unter „Build and deployment“ einstellen:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
5. Speichern.

Der öffentliche Link lautet anschließend ungefähr:
https://DEIN-BENUTZERNAME.github.io/REPOSITORY-NAME/

Hinweise:
- Die Seite benötigt keinen Build-Prozess und keine API-Schlüssel.
- Der PDF-Button öffnet die Druckansicht des Browsers.
- Für einen öffentlichen Link muss GitHub Pages öffentlich erreichbar sein.
